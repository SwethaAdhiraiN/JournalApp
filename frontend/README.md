# JournalApp Frontend

## Structure

- `src/`
  - `components/Homepage/`: Homepage UI, styled via CSS module.
  - `App.jsx`: App entry showing homepage.
  - `index.jsx`: Main ReactDOM render.
  - `global.css`: App-wide styles and resets.
- `public/index.html`: App mount point.

## Scripts

- `npm start` – run locally
- `npm build` – production build

## Tech

- React 18, CSS Modules, clean scalable structure.
- All color/theme variables in CSS; see Homepage.module.css.

## Design

Implements homepage as per `assets/homepage_design_notes.md`.

No routing or API logic included at this stage.
